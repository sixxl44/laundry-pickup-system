# Laundry Pickup System
## CS 385: Software Engineering

**Overview:**
Developed as a term project for the Software Engineering course, this project applies the full software engineering lifecycle to design a Laundry Pickup System 
a platform that lets customers manage their accounts, place laundry orders, schedule pickup and delivery times, pay online, and follow their order status in real time. Laundry staff use the same platform to manage incoming orders, adjust pricing, and coordinate deliveries.

The work spans the complete engineering process, from gathering and specifying requirements through to modeling the system and designing its architecture, using UML diagrams to capture the system's structure, component interactions, and behavior.

**Objectives:**
- Gather and document requirements for a real-world laundry pickup and delivery service.
- Distinguish and define both functional and non-functional requirements.
- Map out how different users interact with the system.
- Capture the system's structure and behavior through UML modeling.
- Propose a software architecture suited to the system's needs.
- Put software engineering methodology into practice on a realistic case.

**System Features:**
- Account creation and profile management for customers
- Location input for pickup and delivery
- Order creation with service selection
- Secure online payment
- Real-time order status tracking
- Coordination with an external delivery provider
- Service and pricing management for staff
- Customer ratings and feedback
- Performance reporting and monitoring

**Concepts & Tools:**
- Requirements Engineering (Functional & Non-Functional)
- System Analysis & Design
- UML Modeling Context, Class, Sequence, and Activity Diagrams
- Client-Server Architecture
